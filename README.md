# 餐點紀錄器

以月曆記錄每天三餐的小工具。純靜態網頁，不需安裝任何東西。

## 使用方式

直接用瀏覽器開啟 `index.html`，或啟用 GitHub Pages 後從網址開啟。

- **餐點清單**：輸入餐點名稱新增，會自動估算熱量；估得不準可直接改數字，清空則恢復自動估算。
- **排三餐**：把清單裡的餐點拖到日曆的早／午／晚格子。手機上先點餐點、再點格子。
- **週 / 月檢視**：右上角可切換。手機預設顯示本週，一天一列、早午晚三欄，左側是精簡的餐點清單；按清單上的「編輯」可展開新增餐點、改熱量、刪除與備份。
- **調整**：格子之間互拖可交換；拖回清單面板或按 × 可清除；點格子可直接打字。
- **🎲**：從清單隨機填滿當天還空著的餐。
- **備份**：資料存在瀏覽器的 localStorage，換裝置或清除瀏覽資料前請先「匯出備份」。

## 熱量估算

依 `foods.js` 內建的常見餐點表比對名稱，數值是一般份量的約略值，僅供參考。

- 可用 `+`、`、` 或空白組合多樣：`雞腿便當+珍珠奶茶`
- 可加數量：`水餃12顆`、`吐司2片`、`白飯半碗`、`肉包x2`
- 表裡沒有的餐點會顯示 `?`，請手動填寫熱量；也可以直接在 `foods.js` 增加項目。
